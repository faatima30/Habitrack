# Habit Tracker Dashboard

## Overview
This project is a **Habit Tracker Dashboard** that helps users monitor their daily habits, track progress, and stay motivated. Users can add, edit, and delete habits while seeing their progress dynamically updated in the dashboard.

## Problem Statement
Many people struggle to maintain consistent habits and track their daily progress. This project provides a simple and interactive way to **visualize and manage habits**, encouraging consistency and productivity.

## Solution
The Habit Tracker solves this problem by providing:
- A **dashboard** showing total habits, completed habits, and daily motivation.
- A **manage habits page** to add, edit, and delete habits.
- **Progress tracking** with visual progress bars and a "Done" button for quick updates.
- **Local storage** ensures data is saved between sessions.

## Technologies Used
- **HTML**: For page structure.
- **CSS**: For styling the dashboard, cards, and modals.
- **JavaScript**: For dynamic DOM manipulation, event handling, and progress tracking.
- **Local Storage**: Stores user habits and daily motivation persistently.

## Key Features
- **Dynamic Content**: Habit cards, progress bars, and stats update instantly using JavaScript.
- **Interactive UI**: Buttons for marking habits as done, editing, and deleting habits.
- **Local Storage**: Keeps habits and daily motivation saved across browser sessions.
- **Dark/Light Mode**: Users can toggle between dark and light themes.

## How to Run the Project
- Clone the repository or download the project files
- Open the project folder
- Open index.html in a web browser
- Start using FocusLearn immediately (no installation required)
